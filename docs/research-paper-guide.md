# How to read a research paper (for this repository)

1. **Abstract and conclusion first.** Write the claim in one sentence.
2. **Find the data.** What dataset, how many rows, what split? Is it public?
3. **Find the baseline.** A result without a fair baseline is not evidence.
4. **Check the metric.** Does it match the decision the work supports?
5. **Look for uncertainty.** Seeds, confidence intervals, number of runs. Reinforcement learning papers often have too few (see `henderson2018`, `agarwal2021` in the source register).
6. **Reproduce a small part.** Run the notebook and compare with the paper's number. If they differ, say so in the notebook.

## Citation rules

Only cite what you read. Verify author, year, venue and DOI against Crossref, arXiv or the publisher. Mark unchecked entries "not verified". Never copy a reference from a chat tool or another list without checking. See [../research/source-register.md](../research/source-register.md).
